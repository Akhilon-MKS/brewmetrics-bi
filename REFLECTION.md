Working on the BrewMetrics Business Intelligence project showed me how AI assistance and version control can be combined with Power BI development. GitHub Copilot was useful during the development of DAX measures because it provided starting points for calculations such as Month-over-Month Growth, Running Total Sales, Product Rank, and Average Transaction Value. These suggestions helped reduce the time required to write the initial DAX expressions.
However, the Copilot suggestions still needed to be checked against the actual data model. In particular, table names, column names, relationships, and filter context had to be verified before using the measures in the report. This showed me that Copilot can assist with generating code, but the generated code still needs to be tested and corrected based on the project requirements.
Working with Git also changed my approach compared with a normal single-file Power BI lab. Instead of treating the report as one completed file, I had to think about the development process in stages. The repository history provided a record of the schema creation, DAX development, and dashboard development. This made the work more organized and made individual changes easier to track.
Overall, the project helped me understand that AI tools are most useful as development assistants, while validation, testing, documentation, and version control are still important parts of the BI development process.
